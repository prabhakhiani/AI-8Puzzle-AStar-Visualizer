04 / CONCEPT GUIDE

How A* finds a solution

g

Cost so far

g(n) is the number of moves from the initial state to the current state. Every legal move costs 1.

h

Estimated cost

h(n) estimates the remaining cost. Manhattan Distance adds tile grid distances; Misplaced Tiles counts incorrect numbered tiles. The blank is excluded.

f

Combined priority

f(n) = g(n) + h(n). A* expands a state with the lowest estimated total cost first. With these admissible heuristics and unit move costs, the solution is optimal.

Manhattan Distance

For every numbered tile, add the horizontal and vertical distance between its current cell and goal cell. It usually gives a more informed estimate than Misplaced Tiles.

Misplaced Tiles

Count each numbered tile that is not in its goal position. It is simple to calculate, but often less informative than Manhattan Distance.
